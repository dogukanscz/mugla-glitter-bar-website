# Fotoğraflar

Bu klasöre aşağıdaki isimlerle `.jpg` (veya `.webp`) dosyaları koyun; site otomatik olarak kullanır.
Dosya yoksa o alanda tasarımla uyumlu bir yer tutucu görünür.

| Dosya                 | Nerede kullanılıyor                        | Önerilen oran |
|-----------------------|--------------------------------------------|---------------|
| hero.jpg              | Açılış ekranı, büyük fotoğraf              | Dikey 4:5     |
| about.jpg             | "Biz kimiz" bölümü                          | Dikey 4:5     |
| festival-1.jpg, -2    | Festival bölümü (büyük dikey + küçük)      | Dikey        |
| service-1.jpg … -5    | Hizmetler listesi (hover görseli)          | Dikey 4:5     |
| event-1.jpg … -5      | Etkinlikler listesi (hover görseli)        | Yatay 3:2     |
| gallery-1.jpg … -N    | Galeri (sınırsız; sırayla yerleşir)        | Karışık       |

Öneri: genişlik en fazla 1800px, kalite %80 civarı. Dosya boyutu 300 KB altı ideal.
